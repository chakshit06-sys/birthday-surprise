# Birthday Surprise — Next.js

An elegant, royal-themed, multi-page birthday microsite with animated backgrounds and slide transitions.

## Run it

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Customize

Edit the `pages` array in `app/page.tsx` to change the messages.

The final cat-kiss GIF currently uses a Tenor-hosted asset:
https://media1.tenor.com/m/-VlI93QJiQMAAAAd/cat-kiss.gif

For a fully self-contained deployment, download a GIF you have permission to use and place it in `public/`, then change `kissGif` to `/your-file.gif`.

## Tech

- Next.js App Router
- TypeScript
- Framer Motion
- Custom CSS
- Responsive/mobile friendly
